# 🐄 QurbaniHat – Livestock Booking Platform

A modern livestock marketplace where users can explore animals for Qurbani and place bookings after authentication.

## 🌐 Live URL
> https://qurbanihat.vercel.app

## ✨ Key Features
- Browse 8+ verified Qurbani animals (cows & goats)
- Filter by type, sort by price
- Email/password + Google OAuth authentication
- Booking form (login required)
- My Profile with photo and name
- Update profile name and photo URL
- Fully responsive design
- Toast notifications
- Animate.css animations
- Custom 404 page

## 📦 NPM Packages Used
| Package | Purpose |
|---|---|
| `next` | React framework |
| `better-auth` | Authentication |
| `react-hot-toast` | Toast notifications |
| `animate.css` | Animations (challenge) |
| `tailwindcss` | Styling |

## 🚀 Getting Started
```bash
npm install
npm run dev
```
